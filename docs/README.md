# 문서 색인

**한국어** | [English](README.en.md)

아래 순서대로 읽는 것을 권합니다. 각 문서는 같은 구성(이 문서에서 배우는 것, 실행 방법, 본문, 결과, 정리)으로 되어 있고 같은 이름의 스크립트(`../tutorials/`)와 실행 로그(`../tutorials/output/`)를 설명합니다. 문서 안의 모든 숫자는 그 로그에서 가져온 것입니다.

| 순서 | 문서 | 내용 |
|---|---|---|
| 1 | [00. 퀵스타트](00_quickstart.md) | 전체 흐름을 한 번 실행합니다. |
| 2 | [01. ED 모델과 파라미터](01_ed_model.md) | 노드, 가중치, 변형식, 파라미터 벡터 $P$의 배치. |
| 3 | [02. 목적함수와 에너지 항](02_energy.md) | 잔차 $F$의 네 항과 정규화, 대응점, 교과서와 다른 점. |
| 4 | [03. 해석적 Jacobian](03_jacobian.md) | 구조, 유한 차분 검증, 원본 Jacobian의 오류, 랭크 부족. |
| 5 | [04. 경사하강법](04_gradient_descent.md) | 안정 한계와 진동. |
| 6 | [05. Gauss–Newton](05_gauss_newton.md) | 좋은 첫 단계와 발산, 작은 특이값. |

| 9 | [08. 모든 솔버 비교](08_compare.md) | 한 표에서 비교하고 숫자를 읽는 법. |
| 부록 | [원본 코드 대비 달라진 점](legacy_changes.md) | 원본 스크립트 8개와의 대응, 버그 수정, 원본 수치 재현법. |
